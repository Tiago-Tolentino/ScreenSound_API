# Projeto de Estudo - Consumo de API com C# 🚀

## 📋 Descrição
Projeto de estudo desenvolvido em **C#** para consumo de API, onde realizamos requisições, extraímos informações e aplicamos filtros específicos aos dados recebidos.

## 🎯 Objetivo
Aprender e praticar:
- Consumo de APIs REST com C#
- Manipulação de dados JSON
- Aplicação de filtros e consultas personalizadas
- Boas práticas de desenvolvimento

## 🛠️ Tecnologias Utilizadas
- [C#](https://docs.microsoft.com/pt-br/dotnet/csharp/)
- [.NET](https://dotnet.microsoft.com/)
- [HttpClient](https://docs.microsoft.com/pt-br/dotnet/api/system.net.http.httpclient)
- [Newtonsoft.Json](https://www.newtonsoft.com/json) (se estiver usando)

## 🔍 Funcionalidades
- ✅ Consumo de API externa
- ✅ Extração de dados
- ✅ Filtragem de informações específicas
- ✅ Exibição de resultados filtrados
